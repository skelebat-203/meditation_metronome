# Meditation Metronome

A simple, offline meditation app for Android: a 1-second metronome you can switch on or off, looping meditative music, and a slow, shuffled slideshow of calming images. No ads, no tracking, no network access.

## Test on desktop (Linux / Windows)

Open `index.html` in a browser (Firefox or Chrome).

## Install

F-Droid and Google Play releases are planned. See the [roadmap](docs/design/0001-roadmap.md).
